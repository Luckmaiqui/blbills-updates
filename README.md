# Duo BL · Atualizações Android

Este é o canal público de instaladores e versões do Duo BL. O repositório do projeto permanece privado.

## Instalar

Baixe o APK em [Releases](https://github.com/Luckmaiqui/blbills-updates/releases/latest). Instale por cima da versão anterior para preservar os dados.

A partir da versão 1.3, o aplicativo verifica este canal e baixa novas versões automaticamente quando habilitado. A partir da 1.5, a instalação só começa após a escolha Instalar agora. O Android pode exigir outra confirmação; em dispositivos compatíveis, a confirmação adicional pode ser dispensada.

Os arquivos baixados pelo atualizador não são salvos em Downloads. O APK temporário privado é removido após ser entregue ao instalador; os temporários são limpos em falhas, cancelamentos e retomadas.

Este canal contém apenas instaladores assinados e informações de versão. Não contém os registros financeiros dos usuários.
